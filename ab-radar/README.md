# Радар АБ: концепт-демо

Три варианта сервиса, который объединяет страницу тиража (Confluence) и АБ-платформу.
Сервис показывает, какие АБ-тесты активны, какие включаются, какие закончены и с каким результатом,
когда можно смотреть результаты и что команда забыла сделать.

**Как открыть:** `index.html` в любом браузере. Файл самодостаточный, без сети и зависимостей.
Данные иллюстративные: сюжеты взяты со страницы тиража, люди, номера SD и ключи вымышлены. «Сегодня» в демо — 11.11.2026.

## Что внутри

| Вкладка | Идея |
|---|---|
| Обзор | Проблема, вопросы к сервису, единый жизненный цикл, правила-напоминалки, сравнение вариантов, рекомендация |
| 1. Пульт | Вкладки «А/Б-тесты» (активные, завершённые с итогом и решением, готовящиеся; в каждом тесте видна фича), «Журнал включений» (лента по дням: что, где, с какой SD) и «Все фичи» (каталог текущих и уже включённых на всех). Напоминания свёрнуты в одну строку над таблицей |
| 2. Умный тираж | Таблица тиража со стадиями, матрицей блоков (Бета+, ГФ…SI4), журналом, вкладкой «Удаление тоглов», историей фич, уже включённых на всех, и поиском |
| 3. Ассистент | Бот в мессенджере: утренняя сводка, события, решение и SD-заявка кнопками; настройки уведомлений |
| Паспорт | Общая карточка эксперимента, открывается кликом по тесту в любом варианте |

## Фича и её АБ-тесты

Фича соответствует строке тиража: у неё одна аналитика, релиз, история итераций и задача на удаление тоглов. Внутри фичи бывает несколько АБ-тестов:

- **параллельные** — один запуск по разным сегментам или рубильникам (лендинги 0/59/99 ₽, `returnNotificationsPrice1/2/3Ab`). У каждого теста своя выборка, поэтому своя дата «можно смотреть», свой результат и своё решение;
- **последовательные** — итерации №32 → №33 и перезапуски с новой версией. Прошлые итерации видны в паспорте в блоке «Что уже пробовали».

Где это видно в демо:

- **Пульт и Ассистент** — напоминания по тестам одной фичи склеиваются в одну строку.
- **Умный тираж** — фича показана строкой, её тесты вложены под неё.
- **Паспорт** — есть переключатель между тестами фичи.
- **Запись решения** — его можно применить сразу к нескольким тестам фичи, у каждого останется свой победитель.

**История: фичи, уже включённые на всех.** В «Умном тираже» есть представление «Включены на всех»: 14 фич 2023–2026 годов со страницы тиража, с АБ и без. У каждой видны итог, дата включения на всех, кто решал, какие тоглы удалены и в какой части «Удаления тоглов». Поиск ищет по названию, тоглу, SD и релизу во всех фичах, включая историю. В Пульте это вкладки «Журнал включений» и «Все фичи», в Ассистенте — команда `/найти`.

**Фича без АБ-теста.** АБ не планируется: регуляторное требование, технический переезд, обновление SDK. Причину указывают при создании. Цикл у такой фичи короче: релиз и пилот → раскатка по блокам → проверка и чистка → архив. Вместо результатов АБ есть контрольная точка: через N дней после 100 % сравнить метрики до и после. Правила следят за затянувшимся пилотом и пропущенной проверкой. Примеры в демо: «Целевое управление по КПС», «Вклады в единый свитчер» (пилот), «RuStore SDK» (без рубильников).

**Длинная история.** У фичи «Активация клиента с 1 продуктом» 33 прошлых теста и сейчас идёт №34. Паспорт показывает:

- сводку: побед, без эффекта, остановлено;
- ленту всех итераций;
- таблицу по темам;
- что из этого сейчас в проде;
- поиск по истории.

Если тему новой итерации уже проверяли, сервис предупредит. В форме «Новая строка в тираже» номер итерации и версия сути подставляются сами.

«Можно смотреть результаты» наступает, когда выполнены оба условия: прошёл минимальный срок и набрано 100 % расчётной выборки при текущем темпе. Если выборка не успевает к плановой дате, срабатывает отдельное напоминание.

## Интерактив

- «Записать решение» в Пульте или паспорте создаёт план раскатки по блокам и переводит тест в «Раскатку решения».
- «Создать SD-заявку» привязывает заявку к шагу включения.
- В Ассистенте сценарий решения проходит целиком в чате.
- «Новый АБ-тест» собирает имя по конвенции `[Команда]. [Платформа]. [Фича]. №N Ветка: [суть] Vn. [варианты]. DD.MM.YYYY`.

## Сборка

Исходники лежат в `src/`. После правок нужно запустить `python3 build.py`: скрипт пересоберёт `index.html`.
